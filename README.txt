漢検3級 QUEST v2
=================

【普段編集するファイル】
questions.js だけです。

例：読み問題を追加
{ type:"reading", q:"慎重", a:"しんちょう" },

QUESTIONS = [ ... ] の中に上の1行を追加してください。

■ ファイル構成
index.html    ゲーム画面（基本触らない）
style.css     デザイン（基本触らない）
game.js       ゲーム処理（基本触らない）
questions.js  問題データ（ここを編集）

■ type
reading  読み
antonym  対義語
synonym  類義語
yoji     四字熟語

■ 4択について
同じtypeの別問題の「正解」から、ハズレ候補を自動で3つ選びます。
そのため同じtypeは最低4問以上入れてください。

ハズレを自分で指定したい場合：
{ type:"reading", q:"穏やか", a:"おだやか",
  wrong:["すこやか","あざやか","ゆるやか"] },

■ PCで確認
index.html をブラウザで開いてください。

■ スマホで使う場合
4ファイルをまとめてWebサーバー/GitHub Pages等へアップロードしてください。
ローカルHTMLをスマホで直接開くと、端末によってはコード表示になる場合があります。
